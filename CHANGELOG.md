# Changelog

## [1.0.0] — 2026-10-28

### Added

- GEVERB ambient reverb for lead guitar, built with JUCE 8.0.8 as VST3 and
  Standalone.
- Eight-line Hadamard FDN with four-stage input diffusion, pre-delay, damping,
  slow decorrelated modulation and up to 30 s decay.
- Plate, Hall and Ambient voices.
- Parallel octave-up shimmer network with filtered feedback.
- Hold/freeze control and click-free, sample-accurate bypass.
- Eight factory atmospheres, including Eno Float, Infinite Sky, Shimmer Veil
  and Lead Into Light.
- Brushed-gunmetal and flush-glass interface with crimson LED edge glow,
  knurled metal knobs, right-side full-height mixer bay, horizontal stereo
  OUT METER with peak hold, and a central live tail-field display.
- Lock-free waveform and stereo output telemetry.
- Offline DSP tests, VST3 host smoke test, screenshots, and cross-platform
  GitHub Actions release builds for Windows x64, Linux x64 and macOS Universal.
